Conversor para Linguagem Simples

Gere uma versão em linguagem simples de uma decisão ou voto — um produto acessório, sem valor jurídico, para acompanhar ou ser publicado ao lado do documento oficial. Não substitui o original.

Provedor de IA (sua chave — fica só no seu navegador)

1 Documentos ou texto

Carregue um ou mais documentos (DOCX, PDF, TXT) — cada um vira um produto. Ou cole/digite um parágrafo.

Arraste arquivos aqui ou clique para escolher (DOCX, PDF, TXT)

2 Prompt de conversão

O padrão é a norma ABNT NBR ISO 24495 (Lei 15.263). Você pode escolher outra técnica ou personalizar.

3 Público-alvo

O LUCAS calibra o vocabulário e o nível de explicação para quem vai ler.

4 Dados para a exportação

Opcionais, mas recomendados: aparecem no rodapé do documento exportado. Se ficarem em branco, entra um aviso-padrão de ressalva.

Resultado

A exportação sai sempre com o aviso de que esta é uma versão em linguagem simples, sem valor jurídico, que não substitui o documento oficial.
